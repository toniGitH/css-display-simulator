<h1 align="center">CSS DISPLAY SIMULATOR</h1>

<br>

Aplicación para practicar, de manera simulada, el comportamiento básico de la propiedad DISPLAY (block/inline/inline-block).

La aplicación no es perfecta, pero te puede ayudar a entender mejor los conceptos CSS de:

- display block
- display inline
- display inline-block

No son los únicos, pero sí los más básicos y fundamentales que hay que tener muy claros a la hora de estudiar CSS y HTML.

Para utilizarlo, simplemente abre el documento display-simulator.html mediante cualquier navegador.
